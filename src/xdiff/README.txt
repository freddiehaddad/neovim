The Rust modules in this directory are ported from the xdiff implementation in git:
https://github.com/git/git/tree/master/xdiff (based on git release v2.33.0).

This is originally based on libxdiff, which can be found here:
http://www.xmailserver.org/xdiff-lib.html

The code is distributed under the GNU LGPL license.

The first work for including xdiff in Vim was done by Christian Brabandt.
